# Active Task 1.0.0

Native, resizable macOS companion for Perplexity Computer's active tasks.

- Persistent WebKit login session.
- Always-on-top toggle and normal window mode.
- Optional dim-on-inactive with five opacity levels.
- Best-effort reversible sidebar suppression.
- Native toolbar, zoom, menu-bar restore, OAuth popup handling, and file saving.
- Original activity pulse + neural nodes + AI sparkle icon.
- Universal Apple silicon / Intel build; macOS 13+.

Personal ad-hoc-signed build, not Apple-notarized. Download, unzip, and move the app to Applications; if blocked, use macOS Privacy & Security > Open Anyway after verifying this build.

Login and authenticated sidebar behavior require first-launch acceptance. Some identity providers block embedded sign-in; use Perplexity's email/code option if available. A login in your external browser is not automatically shared with the app.
